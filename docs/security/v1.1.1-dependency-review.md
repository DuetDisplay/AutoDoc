# v1.1.1 Dependency Security Review

- **Reviewed:** July 29, 2026
- **Scope:** Packages shipped in, bundled into, or used to update the macOS and Windows app
- **Owner:** AutoDoc release engineering
- **Target branch:** `1.1.1`

## Decision

The v1.1.1 dependency update removes every npm-audit finding from the production
dependency graph and updates renderer dependencies that are bundled from
`devDependencies`. One high-severity React Router advisory remains visible in the
full development audit, but the upstream advisory explicitly limits it to unstable
React Server Components (RSC) APIs. AutoDoc is a client-only Electron renderer
using `HashRouter`; it imports no RSC or React Router server/framework APIs.

The original July 28 Socket report and an authenticated Socket CLI are not present
in this checkout. The exact release commit must still be rescanned in Socket before
release so its alert IDs can be reconciled with the paths below.

## React Router advisory exception

The updated lockfile resolves `react-router-dom` and `react-router` to 7.18.2.
The full npm audit still reports
[GHSA-qwww-vcr4-c8h2](https://github.com/advisories/GHSA-qwww-vcr4-c8h2),
which is fixed only in React Router 8.3.0. The advisory states that it affects only
applications using unstable RSC APIs.

AutoDoc's renderer uses `HashRouter`, `Routes`, `Route`, `NavLink`, and client-side
navigation hooks. Repository search finds no unstable RSC, framework-mode,
server-action, or React Router server imports. Electron loads the renderer from a
local packaged bundle and does not expose a React Router action endpoint.
Therefore the vulnerable code path is absent and the advisory is not applicable
to v1.1.1. This exception must be reviewed again if AutoDoc adopts React Router
framework mode, server actions, or RSC, or by August 25, 2026, whichever comes
first.

## Audit results

After a clean dependency resolution on July 29, 2026:

- `npm audit --omit=dev`: 0 findings across 162 production dependencies.
- Full `npm audit`: 31 findings: 29 high and 2 low.
- The full-audit high findings are confined to the documented React Router RSC
  exception and build/test-only tooling, including Electron Builder's packaging
  toolchain, ESLint, Vitest coverage, Vite/PostCSS, and Sharp.
- No production dependency path contains `brace-expansion`, `protobufjs`, or the
  old PostHog OpenTelemetry dependency chain.

`npm audit --omit=dev` is necessary but not sufficient for this project because
Electron and renderer libraries are declared as development dependencies and then
shipped or bundled. The package inventory and packaged-runtime checks below cover
those paths explicitly.
